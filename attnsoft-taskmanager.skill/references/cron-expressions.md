# Cron 表达式参考

## 格式

```
秒 分 时 日 月 周
| | | | | |
| | | | | +--- 星期几 (0-6 或 1-7, 0/1=周日)
| | | | +----- 月份 (1-12)
| | | +------- 日期 (1-31)
| | +--------- 小时 (0-23)
| +----------- 分钟 (0-59)
+------------- 秒 (0-59)
```

## 特殊字符

| 字符 | 说明 | 示例 |
|------|------|------|
| `*` | 任意值 | `*` = 每秒/分/时等 |
| `,` | 分隔多个值 | `1,3,5` = 第 1、3、5 个 |
| `-` | 范围 | `1-5` = 1 到 5 |
| `/` | 增量 | `0/5` = 从 0 开始每 5 个 |
| `?` | 不指定 | 用于日和周的互斥 |
| `L` | 最后 | `L` = 月份最后一天 |
| `W` | 工作日 | `15W` = 15 号最近的工作日 |

## 常用表达式

| 表达式 | 说明 |
|--------|------|
| `0/1 * * * * ?` | 每秒执行 |
| `0 0/1 * * * ?` | 每分钟执行 |
| `0 0 0/1 * * ?` | 每小时执行 |
| `0 0 0 * * ?` | 每天午夜执行 |
| `0 0 9 * * ?` | 每天 9 点执行 |
| `0 0 9 * * 1` | 每周一 9 点执行 |
| `0 0/5 * * * ?` | 每 5 分钟执行 |
| `0 0 9-17 * * 1-5` | 工作日 9-17 点每小时执行 |
| `0 15 2 * * ?` | 每天凌晨 2:15 执行 |
| `0 0/12 7-19 * * ?` | 7-19 点每 12 分钟执行 |
| `0 0 0 * 1 ?` | 每月 1 号午夜执行 |
| `0 0 10 * * MON,FRI` | 每周一和周五 10 点执行 |

## 验证 Cron 表达式

```csharp
bool isValid = QuartzHelper.ValidExpression("0 0/5 * * * ?");
```
